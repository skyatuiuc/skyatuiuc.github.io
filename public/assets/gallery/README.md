# SKY at UIUC — Hero Gallery Photos

Place your photo files in this directory (`public/assets/gallery/`).

### Recommended Setup:
1. Copy your photos into this folder:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`
   - `photo5.jpg`
   - *(or any additional images)*

2. To customize the list or captions, edit [`src/data/heroGalleryData.js`](../../src/data/heroGalleryData.js).

### Supported Formats:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`
- `.avif`

### Recommended Specs:
- Landscape aspect ratio (approx 16:9 or 3:2)
- Resolution: 1920x1080px or higher
- High visual brightness/clarity
